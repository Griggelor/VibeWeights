# VibeWeights — historical project brief (public summary)

The original internal handoff of 26 November 2026 is retained outside this public repository. The initial hypothesis was a modular recurrent neural architecture with independently constructed experts, non-linguistic communication, index-managed memory and separate input/output modules. Direct analytic construction was the original research emphasis, with a planning target of roughly 512 experts of 100M parameters each. These were hypotheses rather than demonstrated capacities. Later decisions supersede the fixed size and permit pretrained bootstrap models, distillation and other explicitly labelled learning paths.

For the detailed public vision and current requirements see [VISION_ARCHITEKTUR_v05.md](VISION_ARCHITEKTUR_v05.md), [ARCHITEKTUR_v06.md](ARCHITEKTUR_v06.md), [MEMORY_ARCHITECTURE_v07.md](MEMORY_ARCHITECTURE_v07.md) and [status.md](status.md).
