## Contract

The new trainer consumes committed verified joint social-use receipts, not source expert weights, host-provided training labels, or unverified candidate outputs. Restricted two-port ABI: exact joint impulse, two signed numeric release fields, at least two actual contributors with positive leave-one-out credit, distinct input token cases, both labels. The trusted local source population and oracle identities, receipt hashes, contributor artifact identities and training data digest are bound in the new candidate manifest. Readout fit revalidates the evidence before and immediately before atomic publication; admitted candidate reload and direct/social execution require revalidation against the persistent source store. Original parents remain intact. Evidence invalidation prevents execution of the usage-derived candidate; existing conventional adapters unaffected. Hashes detect inconsistent modifications, not an adversary rewriting the entire trusted database. No cross-store atomic guarantee or general cascading quarantine; offline memo is an experiment-only wrapper and must not cache usage-derived candidates across source invalidation.

The host still chooses the candidate prefix, port, episode IDs and independent evaluation oracle; this is not autonomous competence discovery or learning a universal input/output adapter. The generic legacy topic head is retained only for A1 artifact compatibility; the social path ignores it. Strict admission requires all training/holdout cases and existing head checks, same as previous A1. No modification of prior expert artifacts or automatic replacement.
